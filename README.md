## 🎨 Confirmed 4-Color Palette & Design Tokens

Built strictly in accordance with the confirmed 4-color palette from the PRD:

| Role | Color Name | Hex Code | UI Purpose |
| :--- | :--- | :--- | :--- |
| **Primary Dark** | Deep burgundy | `#561C24` | Backgrounds, heavy headers, contrast anchors |
| **Secondary** | Wine | `#6D2932` | Card surfaces, interactive buttons, hover states |
| **Accent** | Warm taupe | `#C7B7A3` | Borders, subtle icons, tags, neural mesh lines |
| **Light Surface** | Cream | `#E8D8C4` | Typography in dark mode, light mode background |

Features **three distinct, elegant themes**:
- 🌙 **Dark Burgundy** (`data-theme="dark"`): Deep burgundy (`#561C24`) surfaces with cream typography and wine accents.
- ☀️ **Cream Light** (`data-theme="light"`): Frosted cream (`#E8D8C4`) surfaces with burgundy typography.
- 📜 **Beige & Burgundy** (`data-theme="beige"`): Warm natural linen beige (`#F4EBE1`) parchment surfaces with rich velvety burgundy (`#561C24`) typography and wine buttons.

All themes respect WCAG AA contrast standards, save choice to persistent `localStorage`, and cycle effortlessly via the navbar theme toggle!

## 🚀 How to Preview & Deploy

### Preview Locally via Built-in Server
Run with PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit **`http://localhost:8080/`** in any browser.

### 1-Click Free Deploy to GitHub Pages
```bash
git init
git add .
git commit -m "Update portfolio with verified JPG certificates, Vietnam Best Paper title, and Beige theme"
git remote add origin https://github.com/DISHA-1125/<repo-name>.git
git branch -M main
git push -u origin main
```
In your GitHub repo settings, go to **Pages**, select `main` branch as the source, and save!
